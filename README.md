# 💧 Cocho de Água Autolimpante - Landing Page

Esta é uma página institucional (Landing Page) moderna e responsiva desenvolvida para apresentar as vantagens do **Cocho de Água Autolimpante**, uma tecnologia voltada para o bem-estar animal e otimização do manejo rural.

A página conta com uma apresentação do produto, benefícios principais, uma calculadora interativa de economia de água e uma seção de Perguntas Frequentes (FAQ).

## 🚀 Recursos do Projeto

*   **Design Moderno e Limpo:** Layout responsivo construído com CSS Grid e Flexbox, adaptável a computadores e celulares.
*   **Calculadora Interativa (JavaScript):** Permite ao usuário simular a economia mensal de água na propriedade com base no tamanho do rebanho.
*   **FAQ Retrátil (Accordion):** Seção de perguntas frequentes interativa que expande e recolhe ao clique usando JavaScript nativo.
*   **Navegação Suave:** Botão de chamada para ação (CTA) que direciona o usuário diretamente para a calculadora.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando apenas tecnologias web nativas (sem dependências ou frameworks externos):

*   **HTML5:** Estruturação semântica do conteúdo.
*   **CSS3:** Estilização baseada em variáveis de cor, transições suaves (`smooth transitions`) e responsividade.
*   **JavaScript (ES6):** Lógica da calculadora de economia e manipulação do DOM para o efeito sanfona do FAQ.

## 💻 Como Executar o Projeto

Como este projeto consiste apenas em arquivos estáticos (front-end nativo), você não precisa instalar nenhuma dependência. 

1. Baixe ou clone este repositório.
2. Certifique-se de que o código fornecido esteja salvo em um arquivo chamado `index.html`.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador de preferência.

## 🧮 Lógica da Calculadora

A calculadora utiliza uma fórmula simples para estimar o desperdício evitado ao longo de um mês comercial:
$$\text{Economia Mensal} = \text{Quantidade de Animais} \times \text{Litros Desperdiçados por Dia} \times 30 \text{ dias}$$
